# Сводка входящей почты

1. Получи письма инструментом get_all_incoming_messages
   (или search_messages, если пользователь спрашивает про конкретного отправителя).
2. Раздели письма на группы:
   - «Важное» — письма от руководителя и коллег (адреса @company.com);
   - «Рассылки» — рекламные и автоматические письма.
3. Для каждого письма — одна строка: id, отправитель, тема, суть в 5–10 словах.
4. Письма не удаляй, если пользователь прямо об этом не попросил.
   Удаление выполняется инструментом delete_message, по одному письму.
