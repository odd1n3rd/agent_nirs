# Сводка погоды

1. Если город не назван, возьми его из известных фактов о пользователе.
   Если его там нет — спроси пользователя.
2. Для каждого города вызови get_weather.
3. Ответ оформи так: одна строка на город — «Город: температура, осадки, ветер».
4. В конце дай один короткий совет (зонт, тёплая одежда и т. п.).
